# 99 — Glossaire

← [[00 - Index]]

| Terme | Définition |
|---|---|
| **MJ / DM** | Maître du Jeu / Dungeon Master |
| **PJ / PC** | Personnage-joueur |
| **PNJ / NPC** | Personnage non-joueur |
| **Campagne** | Ensemble de sessions partageant un monde, des personnages et une histoire |
| **Session** | Une séance de jeu |
| **Chronique** | Journal d'événements immuables d'une campagne ([[04 - Épopée Chronique]]) |
| **Événement** | Fait horodaté, typé, avec acteurs/cibles/visibilité |
| **Event sourcing** | État dérivé en rejouant les événements |
| **Constellation** | Graphe 3D de nœuds et liens du MJ ([[06 - Épopée Constellation]]) |
| **Nœud / Lien** | Entité du graphe / relation qualifiée (type, intensité, polarité) |
| **Scène** | Carte + grille + éléments de décor pour un combat |
| **Token (pion)** | Représentation d'une créature sur la scène |
| **Gabarit (template)** | Zone d'effet : cône, sphère, ligne, cube, cylindre |
| **Replay** | Rejeu d'un combat à partir de ses événements |
| **Ruleset** | Configuration d'un jeu : fiche, formules, conditions, contenu ([[09 - Modularité multi-systèmes]]) |
| **SRD** | System Reference Document — contenu D&D publié sous CC-BY-4.0 ([[08 - Contenu et licences]]) |
| **UVTT** | Format *Universal VTT* d'export de cartes avec murs/lumières |
| **VTT** | Virtual TableTop |
| **Homebrew** | Contenu créé par l'utilisateur |
| **MoSCoW** | Must / Should / Could / Won't |
| **ADR** | Architecture Decision Record |
